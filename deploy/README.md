# 部署脚本说明

## 脚本分类
- **Windows**: `*.ps1`, `*.bat`
- **Linux/Mac**: `*.sh`
- **数据库**: `setup-database.*`, `backup-database.*`
- **服务管理**: `stop-*.ps1`, `restart-*.ps1`
- **系统维护**: `update-system.*`

## 使用建议
- Windows 用户: 使用 `deploy-windows.ps1`
- Mac 用户: 使用 `deploy-mac.sh`
- Linux 用户: 使用 `deploy.sh`
